# Magazijn-Applicatie-Ontwerpen

## Windows-desktopapp starten

De MAUI Blazor Hybrid-app gebruikt de gedeelde Razor-schermen uit `Magazijn.Components`.
Start de app vanuit de repository-hoofdmap met:

```powershell
dotnet run --project ".\Magazijn Website\Magazijn Website\Magazijn Desktop\Magazijn.Desktop.csproj" -f net10.0-windows10.0.19041.0
```

De app opent in een Windows-venster. De website blijft een afzonderlijk project.
